The accompanying repository provides experiment notebooks, internal holdout manifests, locked configurations, prompts, saved generations, intervention-level predictions, evaluation tables, and post-review audit outputs. The original DETECH 2026 source dataset is available from the challenge organizers at https://github.com/gmdn/DETECH2026 and is not duplicated here. Large model checkpoints and temporary embedding caches are not included; the code and saved output tables document the reported analyses. Repeating model training or API generation requires access to the named models, appropriate computing resources, and, for generation, an API key. Saved generation outputs allow evaluation without a new API call.
